## 🚀 Key Features

1. **Dynamic Data Layer**: Centralized configuration architecture (`src/data/portfolioData.ts`) decoupled from UI components for seamless updates without code rewrites.
2. **Interactive Developer Workspace**: Real-time syntax-styled IDE interface featuring ASP.NET Core controller snippets, React Native navigation, and PostgreSQL schema definitions.
3. **Interactive 4-Tier Ecosystem**: Visual architecture pipeline connecting Client Interfaces → APIs & Backend → Relational Databases → Development Tools.
4. **Dynamic Project Filtering**: Instant client-side filtering across `All`, `Web`, `Mobile`, `Backend`, `Full-Stack`, and `Database` categories with rich architectural detail modals.
5. **Authentic Certificate Viewer**: Displays the verified EVISION IT SOLUTION Microsoft .NET internship training certificate.
6. **Integrated Resume Viewer & Print**: Modal supporting browser print preview, PDF export, and local download.
7. **Protected Admin Management Console**: Integrated CMS preview (Demo passcode: `admin123`) displaying captured contact inquiries from `localStorage` and architecture schemas.
8. **Contact Service Abstraction**: Validated interactive contact form with state feedback and clean service abstraction for future ASP.NET Core API or EmailJS wiring.
9. **Dark / Light Mode**: Professional high-contrast dark theme by default with smooth light mode toggle.
10. **Production SEO & Accessibility**: Semantic HTML5, ARIA labels, JSON-LD Person schema, robots.txt, sitemap.xml, and keyboard navigation.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository and navigate to directory
cd Uttam_Portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
